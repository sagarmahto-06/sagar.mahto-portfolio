# Sagar — Cherry Blossom Nature Portfolio

Beautiful responsive single-page portfolio. No npm, React or build tools needed.

## Before publishing
Open `index.html` and replace:
- `YOUR_EMAIL@gmail.com`
- `+91 XXXXXXXXXX`
- `YOUR_GITHUB`
- demo project names/descriptions/links
- about text if you want

## GitHub Pages
1. Create a new GitHub repository.
2. Open it → **Add file → Upload files**.
3. Upload all 4 files from this folder.
4. **Commit changes**.
5. Go to **Settings → Pages**.
6. Source: **Deploy from a branch**.
7. Branch: **main**, folder: **/(root)**.
8. **Save** and wait for the Pages URL.

Keep `index.html`, `style.css` and `script.js` together in the repository root.
